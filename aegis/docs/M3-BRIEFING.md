# M3：每日简报（本地版）

> 当前版本只使用本地数据：今天的提醒、待处理数、监测器状态。
> 天气与日历尚未接入，因此不会假装有这两类信息。

## 配置

设置 → 每日简报：

- 启用开关
- 时间（HH:mm）
- 保存后每个 tick 检查；到点当天只生成一次

等价配置：

```json
{
  "briefing": {
    "enabled": true,
    "time": "08:00"
  }
}
```

## 生成内容

```text
今日简报（2026-10-20）

今天有 3 个提醒：
· 09:00 交周报
· 14:30 站会
待处理：2，其中已过期 1
监测器：2 个运行中，最近错误 0
```

- 没有安排时明确写「今天没有安排」
- 监测器错误数来自最近一次扫描
- 通过 `kind=digest` 通知走正常投递链

## 幂等与触发

- 每个 scheduler tick 检查一次
- daemon 启动时也会检查一次（覆盖 8 点后才开机）
- 幂等由 `notification.dedupe_key = briefing:YYYY-MM-DD` 唯一索引裁决
- 不依赖内存日期，重启/多 tick 不会重复

## 当前限制

- 没有天气
- 日历只支持本地 ICS 文件（见 [M3-CALENDAR.md](M3-CALENDAR.md)）
- 没有邮件
- 没有 LLM 摘要；内容是规则拼接
- 没有“本周避免了什么”统计

## 验证

`BriefingService` 测试覆盖：

- 未到点不生成
- 到点生成且当天只生成一次
- 未启用不生成
- 没有安排时的明确文案
- 监测器错误摘要
