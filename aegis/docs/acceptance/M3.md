## 自动报告

```bash
pnpm m3:report
```

输出 `docs/acceptance/m3-report.md`：知识库规模、外发审计、渠道投递、
早报天数、ICS 事件数、未满足项。

## 验收前必须完成

1. 用真实文档跑一次问答，确认引用可点击、无依据时拒答。
2. 至少一个远程渠道成功投递（Webhook/Telegram/Bark/邮件）。
3. 连续 7 天生成早报，且每天有可读内容。
4. 用真实邮箱验证重要邮件命中率/误报率；规则版尚无真实样本。
5. 产品负责人确认“早报有信息量”和“漏报可接受”。

## 明确不在本清单

- M4 员工/团队功能
- PDF/Word 摄取
- IMAP 正文/附件读取
- LLM 邮件语义判断
