## 自动化门禁

每天至少跑一次：

```bash
pnpm acceptance
```

周末或重要改动后跑完整版：

```bash
pnpm acceptance --full
```

结果写入 `docs/acceptance/last-run.json`（已 gitignore）。失败时不要跳过，
先修 M1 缺陷再继续。

## 手工验收清单

- [ ] 一次性提醒到点；通知/窗口卡片可见
- [ ] 「完成」后从列表消失；重复提醒只结束本次
- [ ] 「稍后提醒」默认 5 分钟，任务仍在列表并显示下一次时间；到点再次提醒
- [ ] 编辑标题/备注/时间/重复；改期后旧时间不再触发
- [ ] 免打扰时段普通提醒延后、重要提醒穿透
- [ ] 关机/休眠超过补偿窗口后恢复，不重复、不遗漏
- [ ] 停机超过 15 分钟后启动，出现「我有一段时间没有运行」缺口通知
- [ ] 崩溃/强杀 daemon 后自动恢复
- [ ] 菜单栏图标可显示/隐藏窗口；⌘W 隐藏；⌘Q 两次完全退出
- [ ] 设置页「导出备份」能生成 `aegis.db` + `manifest.json`
- [ ] 开机自启开关可安装/卸载；通知设置按钮可打开系统设置
- [ ] `pnpm acceptance` 全绿，且 `docs/acceptance/last-run.json` 记录当天结果

## 结束判据

14 天结束时，如果：

1. 每日记录没有未解释的漏提醒/重复提醒；
2. 手工清单全部通过；
3. `pnpm acceptance --full` 通过；
4. 没有未修的 M1 缺陷；

则 R5 通过，可以开 M2。否则继续修 M1，不进入 M2。
