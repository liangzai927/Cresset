# M3 缩短验收方案（2–3 天）

> 状态：**产品负责人已批准执行（2026-10-21），尚未执行**。
> 本方案不替代完整的 7 天观察；它是产品负责人明确接受风险后的加速验收路径。

## 为什么需要这个方案

M3 的完整验收要求“早报连续 7 天有信息量”。7 天只能靠真实时间积累。

为了在不直接跳过验证的情况下尽快进入 M4，本方案用：

```text
24–48 小时稳定性冒烟
+ 真实文档问答
+ 远程渠道真实投递
+ 邮箱样本
+ L2 阻断实验
+ 2 次早报
```

换取：

```text
7 天长期运行观察的豁免
```

## 需要产品负责人明确确认

执行前请确认：

1. 接受“未覆盖 7 天长期运行”的风险
2. 接受“真实邮箱样本有限，误报率未统计”
3. 同意在 `docs/acceptance/M3.md` 记录豁免
4. 其余安全门禁不豁免

## 时间安排

| 时间 | 动作 | 产出 |
| --- | --- | --- |
| Day 0（45–60 分钟） | 配置模型/天气/日历/知识库/Webhook/早报 | 可运行环境 |
| Day 1（60–90 分钟） | 问答、引用、拒答、L2 阻断、远程、日历、邮件 | 功能证据 |
| Day 2（30 分钟） | 第二次早报、稳定性、报告 | 稳定性证据 |
| Day 3（30 分钟） | 收尾、签字、更新验收文档 | 验收结论 |

## 测试素材

全部在 [`testdata/m3-acceptance/`](../../testdata/m3-acceptance/)：

- 5 份知识库文档
- 1 个 ICS 日历（含冲突）
- 3 封邮件模板
- 1 个本地 Webhook 接收端
- 问题清单、检查表、证据模板

## 通过标准

| 项 | 门槛 |
| --- | --- |
| 知识库问答 | 10 题中 ≥8 题引用正确 |
| 无依据拒答 | 全部拒答 |
| 引用 | ≥5 条可点击打开正确文件 |
| L2 阻断 | `maxOutboundClass=L1` 时不调用模型 |
| Webhook | ≥1 条真实 success |
| 日历 | 会前提醒 + 冲突各 ≥1 次 |
| 早报 | 连续 2 天，无重复 |
| IMAP（如启用） | 合同/面试命中，营销不命中 |
| 稳定性 | 24–48 小时无崩溃/重启循环 |
| 工程门禁 | `pnpm verify` + `package:verify` |

## 未覆盖风险

- 7 天长期运行、内存泄漏
- 睡眠/唤醒、跨时区、DST
- 真实邮箱误报率
- 30 天数据库增长
- 正式签名/公证
- PDF / Git 导入
