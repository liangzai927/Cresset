# M3：重要邮件监测（IMAP，规则版）

> 规则筛选：发件人白名单 OR 主题关键词；规则未命中时可选用 LLM 做语义判断。
> 只读取未读邮件的发件人/主题/UID，不下载正文与附件。
>
> 配置步骤见 [M3-EMAIL-SETUP.md](M3-EMAIL-SETUP.md)。

## 配置

设置 → 重要邮件（IMAP）：

- IMAP host / port / TLS
- 用户名、邮箱文件夹
- 轮询秒数（≥60）
- 重要发件人（逗号分隔，子串匹配）
- 主题关键词（逗号分隔，不区分大小写）
- IMAP 密码 → 只写入系统钥匙串
- 「测试连接」只做登录 + 打开文件夹

密码存储：

```text
service: com.aegis.credentials
account: email.imap.password
```

## 判定规则

```text
重要 = 发件人命中白名单
    OR 主题命中关键词
    OR （启用 LLM 且规则未命中时）模型判断 important=true
```

### LLM 语义判断（可选）

设置页勾选「规则未命中时用 LLM 判断」。

- 只发送发件人 + 主题，不发送正文/附件
- 数据分级按 L2；`maxOutboundClass=L1` 时会被网关阻断
- 每次判断消耗一次每日调用额度
- 网关阻断/模型失败时**不标记已读**，下一轮再试
- 没有 LLM/额度时不猜测，保持“不是重要邮件”

隐私提示：发件人/主题仍属于个人信息，开启前请确认模型服务商可接受。

默认关键词：`紧急 / urgent / 合同 / 发票 / 面试 / deadline`。

- 没有配置任何规则时，不会把邮件判为重要（安全默认）
- 未读邮件处理后会标记 `\Seen`
- 同一封邮件用 `email:<uidValidity>:<uid>` 去重
- 命中后生成 `kind=monitor`、`priority=high` 的通知

## 限制

- 不读取正文/附件
- LLM 语义判断关闭时仍有规则误判
- 只轮询，没有 IMAP IDLE 实时推送
- 只支持单一邮箱/文件夹
- 首次启用时可能把历史未读邮件当新邮件（建议先清理未读）

## 验证

- 规则单测：发件人命中、关键词命中、无规则不命中
- IMAP 连接测试由设置页按钮触发
