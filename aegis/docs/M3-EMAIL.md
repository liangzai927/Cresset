# M3：重要邮件监测（IMAP，规则版）

> 目前是**规则筛选**：发件人白名单 OR 主题关键词。没有 LLM 语义判断；
> 只读取未读邮件的发件人/主题/UID，不下载正文与附件。

## 配置

设置 → 重要邮件（IMAP）：

- IMAP host / port / TLS
- 用户名、邮箱文件夹
- 轮询秒数（≥60）
- 重要发件人（逗号分隔，子串匹配）
- 主题关键词（逗号分隔，不区分大小写）
- IMAP 密码 → 只写入系统钥匙串
- 「测试连接」只做登录 + 打开文件夹

密码存储：

```text
service: com.aegis.credentials
account: email.imap.password
```

## 判定规则

```text
重要 = 发件人包含任一台白名单  OR  主题包含任一关键词
```

默认关键词：`紧急 / urgent / 合同 / 发票 / 面试 / deadline`。

- 没有配置任何规则时，不会把邮件判为重要（安全默认）
- 未读邮件处理后会标记 `\Seen`
- 同一封邮件用 `email:<uidValidity>:<uid>` 去重
- 命中后生成 `kind=monitor`、`priority=high` 的通知

## 限制

- 不读取正文/附件
- 没有 LLM 语义判断（营销邮件/真重要邮件可能误判）
- 只轮询，没有 IMAP IDLE 实时推送
- 只支持单一邮箱/文件夹
- 首次启用时可能把历史未读邮件当新邮件（建议先清理未读）

## 验证

- 规则单测：发件人命中、关键词命中、无规则不命中
- IMAP 连接测试由设置页按钮触发
