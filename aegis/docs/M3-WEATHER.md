# M3：天气（Open-Meteo）

> 早报里的天气来自 Open-Meteo，无需 API Key。只发送经纬度，
> 不发送提醒内容、邮件或知识库文本。

## 配置

设置 → 天气：

- 启用
- 地区下拉框（按住 ⌘ 多选）
- 不需要手填经纬度；预设地区自带坐标

等价配置：

```json
{
  "weather": {
    "enabled": true,
    "locations": [
      { "name": "上海", "latitude": 31.2304, "longitude": 121.4737 },
      { "name": "北京", "latitude": 39.9042, "longitude": 116.4074 }
    ]
  }
}
```

## 早报表现

```text
天气（上海）：晴 12–20°C
天气（北京）：多云 8–15°C
今天有 3 个提醒：
...
```

## 可靠性

- 缓存 30 分钟
- 请求 8 秒超时
- 失败时保留旧缓存
- 没有缓存时天气行直接缺席，不阻断简报
- 日志只记录失败类别，不记录坐标以外的内容

## 验证

- 多地区解析/缓存
- 单个地区失败保留旧缓存
- 失败返回 null 不抛错
- WMO weather_code → 中文
- BriefingService 包含天气行
